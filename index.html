Convertisseur de données

Boite à malices pour monzoo : de l'ancien fichier .db vers un fichier .json importable.

Vos données restent chez vous

La conversion se fait entièrement dans votre navigateur. Le fichier n'est envoyé nulle part et aucun serveur ne le reçoit.

Comment faire

  1. Déposez ci-dessous votre ancien fichier Boite_à_malices_pour_monzoo.db (ancienne version du script avec Greasemonkey).
  2. Téléchargez le fichier .json obtenu.
  3. Sur la page d'accueil de monzoo, ouvrez « Parcs enregistrés sur ce PC » et cliquez sur « Importer mes données (fichier JSON) ».
Déposez votre fichier .db ici ou cliquez pour le choisir

Conversion terminée

Gardez ce fichier pour vous : il contient vos données de jeu.
